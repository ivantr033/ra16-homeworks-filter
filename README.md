# Домашнее задание к блоку «События и состояние» — Задача «Портфолио с фильтрами»

Веб-приложение для динамического отображения и фильтрации карточек портфолио по категориям, разработанное в рамках курса Netology.

[![Build Status](https://github.com/ivantr033/ra16-homeworks-filter/actions/workflows/deploy.yml/badge.svg)](https://github.com/ivantr033/ra16-homeworks-filter/actions/workflows/deploy.yml)

## 🌐 Ссылка на развертывание (GitHub Pages)
*   **Portfolio with filter:** [Открыть приложение](https://ivantr033.github.io/ra16-homeworks-filter/)

## 🚀 Функциональность и архитектура

Приложение построено на базе компонентного подхода React с чётким разделением ответственности:

- **`Portfolio` (Классовый компонент):** Главный управляющий компонент. Хранит состояние активного фильтра (`this.state.selected`) и выполняет фильтрацию массива данных.
- **`Toolbar` (Функциональный компонент):** Отвечает за рендеринг кнопок переключения категорий. Подсвечивает активный фильтр с помощью динамических CSS-классов.
- **`ProjectList` (Функциональный компонент):** Принимает отфильтрованный массив проектов и отображает сетку изображений, сохраняя оригинальные пропорции макета (эффект Masonry/mampostería).

## 🛠️ Технологический стек

- **Frontend:** React 19, JSX
- **Сборщик:** Vite 8
- **Стилизация:** Чистый CSS3 (использование свойств `column-count` и `break-inside` для создания адаптивного плиточного интерфейса без деформации картинок).
- **CI/CD:** GitHub Actions (автоматический деплой на GitHub Pages).

## 🔧 Локальное развертывание

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите сервер для разработки:

   ```bash
   npm run dev
   ```

4. Откройте локальный адрес в браузере: `http://localhost:5173`

## 📦 Сборка и деплой

Проект настроен на автоматическую публикацию при каждом пуше в ветку `main`. Процесс сборки генерирует статические файлы в директорию `/dist`, которые отправляются на хостинг GitHub Pages.
